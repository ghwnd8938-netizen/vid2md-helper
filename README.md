# vid2md-helper

**vid2md**(영상·녹음을 글로 바꾸는 개인 서비스)의 **서브 서버**입니다. 긴 녹음을 5분 부분으로 나눠 여러 서버가
함께 받아쓸 때, 이 저장소의 GitHub 실행기가 그 부분을 받아씁니다. 화면도, 데이터도, 설정 화면도 없습니다.

## 하는 일

1. vid2md 대시보드가 긴 녹음을 나누면 이 저장소의 작업 흐름(`vid2md helper`)을 실행기 몇 대로 시작합니다.
2. 각 실행기는 부분 하나를 받아 그 구간의 소리만 받아쓰고, 결과를 대시보드에 돌려줍니다.
3. 더 받을 부분이 없으면 꺼집니다. 실행기는 매번 새로 만들어졌다가 통째로 지워지는 임시 컴퓨터입니다.

## 보안

- **서브 전용 키**만 씁니다(저장소 비밀 값, 공개되지 않음). 이 키로 할 수 있는 일은 "나눠진 부분을 받아쓰고
  결과를 돌려주기"뿐입니다. 작업 전체를 가져가거나, 구글 드라이브에 접근하거나, 사전을 보거나, 전사본을 읽을 수 없습니다.
- **소리만** 받습니다(MP3나 녹음 파일). 영상은 받지 않습니다.
- **로그에는 작업 번호와 부분 번호만** 남습니다. 제목, 용어, 받아쓴 글이 담길 수 있는 줄은 "내용 숨김"으로
  바뀝니다(`QuietLogs`, 테스트로 확인).
- 이 저장소에는 작업 서버 코드만 있습니다. 백엔드, 사전, 데이터는 없습니다.
- 작업 흐름은 저장소 관리자만 시작할 수 있습니다(`workflow_dispatch`). 다른 사람이 저장소를 복사해도 비밀 값은 따라가지 않습니다.

## 설정

- 저장소 비밀 값: `VID2MD_API_URL`(대시보드 백엔드 주소), `VID2MD_WORKER_SECRET`(백엔드의 `WORKER_SECRET_HELPER`).
- 이 저장소의 파일은 원본 저장소의 `deploy/helper/bundle.sh`로 만듭니다. 여기서 직접 고치지 마세요.

---

**vid2md-helper** is a helper worker for vid2md, a personal service that turns recordings into text. When a long
recording is split into five-minute parts, runners of this repository transcribe some of them and send the text back.
Its key can do nothing but that, it only ever receives sound (never video), and its log shows job and part numbers
only. Files here are generated by `deploy/helper/bundle.sh` in the source repository.
